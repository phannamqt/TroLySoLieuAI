Hãy tạo một project hoàn chỉnh tên `Excel_AI_Starter` dành cho nhân viên không biết lập trình, sử dụng Windows 10/11.

Mục tiêu của project:

* Tự động cài đặt Python.
* Tự động cài đặt Visual Studio Code.
* Tự động cài extension Python cho VS Code.
* Tự động cài extension OpenAI Codex cho VS Code.
* Cài các thư viện Python cần thiết để xử lý file Excel.
* Tạo sẵn môi trường làm việc đơn giản cho nhân viên non-IT.
* Người dùng chỉ cần bỏ file Excel vào thư mục `input`, mở VS Code và nhập yêu cầu bằng tiếng Việt cho Codex.
* Không được ghi đè file Excel gốc.
* Tất cả kết quả phải xuất vào thư mục `output`.

Hãy tạo đầy đủ cấu trúc project như sau:

```text
Excel_AI_Starter/
├── 01_CAI_DAT_CONG_CU.bat
├── 02_KIEM_TRA_MOI_TRUONG.bat
├── 03_MO_CONG_CU_AI.cmd
├── 04_GO_CAI_DAT.bat
├── AGENTS.md
├── requirements.txt
├── HUONG_DAN_SU_DUNG.md
├── PROMPT_MAU.md
├── input/
│   └── BO_FILE_EXCEL_VAO_DAY.txt
├── output/
│   └── KET_QUA_SE_NAM_O_DAY.txt
├── scripts/
├── logs/
└── templates/
```

## 1. Yêu cầu file `01_CAI_DAT_CONG_CU.bat`

Viết file batch chạy được trên Windows 10 và Windows 11.

File phải thực hiện các bước:

1. Kiểm tra quyền Administrator.
2. Nếu chưa chạy bằng Administrator thì tự mở lại bằng quyền Administrator.
3. Kiểm tra máy đã có `winget` hay chưa.
4. Nếu không có `winget`, thông báo rõ cho người dùng và hướng dẫn cài App Installer.
5. Kiểm tra Python đã được cài chưa.
6. Nếu chưa có Python thì cài Python bản ổn định bằng `winget`.
7. Khi cài Python phải bảo đảm Python được thêm vào PATH.
8. Kiểm tra VS Code đã được cài chưa.
9. Nếu chưa có VS Code thì cài bằng `winget`.
10. Cài extension Python của Microsoft cho VS Code.
11. Cài extension Pylance.
12. Cài extension Jupyter.
13. Cài extension OpenAI Codex nếu xác định được đúng extension ID.
14. Nếu không chắc chắn extension ID của Codex thì:

    * không tự bịa extension ID;
    * mở trang Extensions của VS Code;
    * hướng dẫn người dùng tìm từ khóa `Codex`;
    * hiển thị thông báo bằng tiếng Việt.
15. Chạy lệnh cập nhật pip.
16. Cài thư viện từ `requirements.txt`.
17. Tạo các thư mục `input`, `output`, `scripts`, `logs`, `templates` nếu chưa tồn tại.
18. Tạo shortcut ngoài Desktop để chạy file `03_MO_CONG_CU_AI.cmd`.
19. Sau khi cài xong, mở project bằng VS Code.
20. Hiển thị hướng dẫn người dùng đăng nhập tài khoản Codex.
21. Không lưu tài khoản, mật khẩu, API key hoặc token trong source code.
22. Ghi log quá trình cài đặt vào `logs/install.log`.
23. Nếu một bước lỗi, phải thông báo rõ bước nào lỗi.
24. Không đóng cửa sổ ngay khi có lỗi.
25. Tất cả thông báo hiển thị bằng tiếng Việt, không dấu nếu batch gặp lỗi encoding.

File batch phải có chú thích rõ từng phần để bộ phận CNTT dễ bảo trì.

## 7. Yêu cầu file `PROMPT_MAU.md`

Tạo tối thiểu 10 prompt mẫu bằng tiếng Việt cho các trường hợp:

1. Lọc dữ liệu theo điều kiện.
2. Xóa dòng trùng.
3. Đối chiếu hai file Excel.
4. Đối chiếu hai sheet.
5. Gộp nhiều file Excel.
6. Chia file theo phòng ban.
7. Tổng hợp doanh thu.
8. Tổng hợp dữ liệu theo tháng.
9. Chuẩn hóa ngày tháng và số tiền.
10. Tìm dữ liệu thiếu hoặc bất thường.

Mỗi prompt phải có cấu trúc:

```text
Hãy phân tích file Excel trong thư mục input.

Yêu cầu nghiệp vụ:
[Mô tả yêu cầu]

Nguyên tắc:
- Không sửa file gốc.
- Xuất file kết quả vào output.
- Giữ nguyên dữ liệu gốc trong một sheet riêng.
- Tạo sheet kết quả.
- Báo số dòng trước và sau xử lý.
- Báo các dòng lỗi.
- Tạo script Python trong scripts.
- Tạo file RUN.cmd để chạy lại.
```

Tạo thêm một prompt tổng quát để nhân viên chỉ cần điền:

* Tên file.
* Tên sheet.
* Cột cần xử lý.
* Điều kiện xử lý.
* Kết quả mong muốn.
