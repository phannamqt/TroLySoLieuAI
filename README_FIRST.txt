CHAO BAN!

Day la bo cong cu giup ban xu ly file Excel bang tieng Viet,
KHONG can biet lap trinh.

-----------------------------------------------------------
  BAT DAU O DAY (chi lam 1 lan)
-----------------------------------------------------------

  BUOC 1:
    - Bam CHUOT PHAI vao file:  01_CAI_DAT_CONG_CU.bat
    - Chon:  Run as administrator  (Chay bang quyen quan tri)
    - Neu Windows hoi, bam:  Yes
    - Cho den khi thay dong:  "CAI DAT HOAN TAT!"
    - KHONG dong cua so trong luc dang cai.

  BUOC 2 (khuyen khich):
    - Bam dup vao:  02_KIEM_TRA_MOI_TRUONG.bat
    - De kiem tra moi thu da san sang chua.

-----------------------------------------------------------
  DUNG HANG NGAY
-----------------------------------------------------------

  1. Bo file Excel vao thu muc:  input
  2. Bam dup:  03_MO_CONG_CU_AI.cmd  (hoac shortcut tren Desktop)
  3. Trong VS Code, mo Codex (Ctrl+Shift+X de cai neu chua co).
  4. Dang nhap Codex bang TAI KHOAN CONG TY cap.
  5. Mo file:  PROMPT_MAU.md  -> copy 1 prompt -> sua yeu cau -> gui.
  6. Xem ket qua trong thu muc:  output
